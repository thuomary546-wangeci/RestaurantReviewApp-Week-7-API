# Screenshot checklist for submission

Save the screenshots you capture while running the project in this folder. Suggested filenames:

1. `01-project-structure.png` — VS Code showing both project folders and key source files.
2. `02-api-swagger.png` — Swagger UI showing the restaurant endpoints.
3. `03-get-all-json.png` — GET `/api/restaurants` response containing JSON.
4. `04-restaurant-list.png` — Blazor restaurant list at `http://localhost:5255/restaurants`.
5. `05-restaurant-details.png` — details page for a selected restaurant.
6. `06-add-restaurant.png` — Add Restaurant form.
7. `07-after-add.png` — restaurant list showing the newly added restaurant.
8. `08-edit-restaurant.png` — Edit Restaurant form or the updated record.
9. `09-delete-confirmation.png` — Delete confirmation page.
10. `10-after-delete.png` — list after deleting a restaurant.
11. `11-add-review.png` — Add Review form and/or the added review.
12. `12-github-repository.png` — GitHub repository page showing committed source files.

Take the screenshots yourself after the API and UI are running. The ZIP does not include fabricated screenshots.
